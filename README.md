# Youssef & Ihssane – Wedding Invitation

Animated 9:16 digital invitation (FR / EN). Single self-contained file: `index.html` (photo, styles and script inside; only Google Fonts load online).

## Publish on GitHub Pages
1. Create a new repository (e.g. `wedding-invitation`) and upload these files to the root.
2. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.**
3. After a minute the invitation is live at `https://<your-username>.github.io/<repository-name>/`. Share that link.

## Edit
- Timeline times: search `var EVENTS` in `index.html`.
- Location button: search `maps.app.goo.gl`.
- Timings per page (seconds): search `var D =`.
